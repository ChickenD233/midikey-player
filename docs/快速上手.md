# 快速上手

只讲最基本的：让一个 MIDI 文件在目标程序里响起来。全程 2 分钟。
想看改谱、合奏、键位方案这些，去 [图文教程](图文教程.md)。

## 1. 下载

仓库右侧 **Releases** → 下载最新的 `MidiKeyPlayer-win-x64-x.x.x.zip` → 解压 → 双击 `MidiKeyPlayer.exe`。

弹窗都放行：UAC 选「是」，SmartScreen 选「更多信息」→「仍要运行」。
杀毒报「模拟按键」是误报，把 exe 和 `%TEMP%\.net` 一起加白名单。

## 2. 打开文件，选主旋律

![主界面](images/01-main.png)

1. 点左上「**打开 MIDI 文件 / 文件夹**」，选一个 `.mid` 文件。
2. 左下声轨列表里，点一行作为主旋律（选中的行带 **●** 标记）。

## 3. 播放

1. 按 **F6**（或点「▶ 播放」）。倒计时开始，默认 3 秒。
2. **倒计时内点一下目标窗口**，让它在前台。到点自动开弹。

想停：再按 **F6**（暂停 / 继续），或点「■ 停止」。鼠标键盘失控就狂按 **F6**。

## 没反应？按顺序查这 4 条

1. 目标程序是**窗口化 / 无边框窗口化**（全屏独占收不到按键）。
2. 播放前**点过目标窗口**。
3. 输入法切到**英文**。
4. 目标程序是管理员运行的话，本程序也得是管理员。

就这些。其余功能见 [图文教程](图文教程.md) 和 [README](../README.md)。
